# ESP32-CAM Streaming Optimization

Optimización del streaming de vídeo de una ESP32-CAM
con sensor OV2640 mediante MJPEG.

## Objetivos

- Mejorar la fluidez del streaming.
- Reducir la sobrecarga del procesamiento de imágenes.
- Analizar el rendimiento de la implementación.
- Documentar las decisiones técnicas y los resultados.

## Artículo relacionado

Este proyecto forma parte de los experimentos publicados en
[Fuera del setup](https://www.fueradelsetup.es/).
